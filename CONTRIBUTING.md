# Руководство для контрибьюторов

Спасибо за интерес к проекту!

## Как внести вклад

### Сообщение об ошибках

1. Проверьте, что ошибка ещё не reported
2. Используйте шаблон:
   - Описание проблемы
   - Шаги для воспроизведения
   - Ожидаемое vs фактическое поведение
   - Скриншоты (если применимо)

### Предложение улучшений

1. Опишите текущее поведение
2. Предложите улучшение
3. Объясните, почему это полезно

### Pull Requests

1. Форкните репозиторий
2. Создайте ветку: `feature/your-feature` или `fix/bug-description`
3. Внесите изменения
4. Добавьте тесты
5. Убедитесь, что все тесты проходят
6. Обновите документацию
7. Отправьте Pull Request

## Соглашения о коде

- Используйте snake_case для переменных и функций
- Добавляйте docstrings к функциям
- Следуйте PEP 8
- Максимальная длина строки: 100 символов

## Тестирование

```bash
# Быстрые тесты
python tests/quick_tests.py

# Все тесты
python -m pytest -v
```
